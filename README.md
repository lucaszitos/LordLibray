# LordLibray

**Purpose LordLibray**: A Python toolkit for statistical analysis and text correction. It uses spaCy for named entity recognition (NER) and optimized search algorithms to detect discrepancies in large text body.

**Contains**:

- Natural Language Processing (NLP) from **SpaCy**
- **Efficient Indexing:** Uses **Hash Tables** for $O(1)$ lookup performance during word counting.
- **EPUB Parsing:** Automated text extraction from ebook formats.
